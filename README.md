# 💫About Me :

## 👨‍💻 About Me

Hello, World! I'm a passionate software developer who loves turning ideas into working products.
I enjoy building applications end to end, from designing the database and writing APIs to crafting a clean, easy-to-use interface.

I care about writing code that is simple, reliable, and easy for the next person to understand, and I love working on problems where technology makes someone's day a little easier.

> *"Develop new things to make a happy world."* 🌍

## 🌱 What I'm Up To

- 🔭 Building full stack web applications
- 🤖 Exploring how AI and LLMs can make everyday software smarter
- 📚 Learning something new every week, from system design to cloud
- 🤝 Always happy to collaborate, share ideas, and learn from others

## 🚀 What I've Built

Most of my professional work lives in private repositories, so here is a snapshot of the kind of things I build:

- 🤖 **AI Orchestration Platform (POC):** a multi-agent system where specialized AI agents work together across the software delivery lifecycle, with model routing across Claude, GPT-4o and Gemini, semantic search with pgvector, and multi-tenant access control
- 🏢 **Enterprise Web Platform:** shipped many feature modules and modernized legacy APIs on a platform used by thousands of users across many companies
- 🖼️ **AI Image Comparison:** an automated before/after photo checker that cuts down manual inspection work
- 🔌 **Data Integration Pipelines:** reliable flows that pull data from external APIs with transformation and validation
- 🏛️ **Citizen Service Portals:** secure, high-traffic platforms with role-based access, real-time dashboards and optimized PostgreSQL queries
